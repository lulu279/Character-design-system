# Outfits

本版将六个角色的服装Prompt扩写为可直接用于单图生成的完整中文描述，并为不确定归属的零散服装建立独立卡片。

## 重要文件
- `LYRIC_SCENE_INDEX.md`：歌词剧情服装与分镜关系，避免把同一服装的三格场景重复计数。
- `00_AUDIT_AND_RECOVERY_NOTES.md`：历史服装恢复范围、证据等级和视觉漂移排除。
- `ASSET_REGISTER.csv`：全库服装索引。

## 提示词使用
每次生图先复制对应角色的README身份锁，再复制目标服装的完整Prompt，最后单独补充动作、神态、机位、场景和风格卡。每次只生成一张独立插画。

## 证据等级
- E1：用户明确确认或纠正。
- E2：历史Prompt、项目文件或图集元数据直接支持。
- E3：从已生成图像/设定图提取。
- E4：仅恢复名称或主题，本版为重建稿，不能冒充历史原文。

候选或重建稿不得自动变成角色标准服装；未决定归属的服装不得自动绑定角色。
