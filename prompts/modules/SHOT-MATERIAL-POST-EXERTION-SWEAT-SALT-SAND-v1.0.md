# SHOT-MATERIAL-POST-EXERTION｜运动后汗水、海水与泥沙状态

**状态：** `user_constraint_confirmed_for_coastal_sports_shots`  
**类型：** SHOT 材质 / 状态模块，不是 STYLE 卡。

## 1. 身体状态

- 汗水 / 海水：额角、太阳穴、脸颊、颈侧、肩膀、手臂、锁骨附近、大腿、膝盖、小腿和脚背出现可见汗珠或水珠。
- 发丝：局部湿润，发梢略微下垂并可有少量滴水，或贴近皮肤；不要所有发丝都变成一整片湿发。
- 呼吸与表情：可有轻微喘息、专注、疲惫、满足或休息中的放松，不要求微笑或看镜头。

## 2. 污渍分布

- 泥沙、岩粉和盐渍主要出现在前臂、膝盖、大腿外侧、小腿、脚背、脚趾、脚底和凉鞋接触处。
- 服装相对干净；只允许合理的少量湿边或接触印迹。
- 不要把大量泥污集中涂在外套、上衣和短裤上。

## 3. 服装状态

用户要求的运动后潮池场景中，外套脱下，只保留蓝白运动上衣与功能短裤。其他运动场景按对应 SHOT 决定是否穿外套。

## 4. 失败判据

- 汗水只有皮肤塑料高光，没有可识别水珠。
- 污渍主要集中在衣服，而非身体 / 腿部 / 足部。
- 皮肤过度磨皮，失去汗水和泥沙的附着感。
- 正午场景却使用夕阳色温。
