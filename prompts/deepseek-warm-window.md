# DeepSeek 鲸鱼娘 · 厨房暖逆光

搭配 [角色卡](../characters/CHAR-DEEPSEEK-v1.0.md) 与 [窗边暖逆光风格卡](../styles/STYLE-WARM-WINDOW-v1.0.md)。包内厨房图是画面示例。下面的提示词根据示例整理，加入尾根与衣装开口的复用约束。

```text
画一张竖幅单场景的日常插画。DeepSeek 鲸鱼娘在傍晚的厨房灶台旁煮东西。
她有约七头身的成年体态、深海蓝渐变长发、蓝瞳和一对蓝白鳍状耳。
穿浅色家居裙和短围裙，后腰为宽厚的鲸尾根留出开口。蓝白虎鲸尾巴从
骶尾正中自然延伸，尾柄渐收，末端是水平双叶尾鳍。两条人腿各自落地，
让尾根与后腰衣片的连接在侧后视角可辨认。

镜头在灶台侧后方，保留头到脚及主要尾鳍轮廓。她一手用木勺轻搅锅，
另一手扶锅柄，微微回头，神态放松。后方窗户透入暖金色侧逆光，照出
发梢、蒸汽和棉布的软边。暗面保留灰蓝层次，前景轻微虚化，脸和手最清楚。
整体低饱和，以细线、柔和明暗和局部轮廓光呈现。单一画面，无分栏与文字。
```
