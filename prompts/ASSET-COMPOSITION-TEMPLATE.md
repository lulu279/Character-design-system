# Asset Composition Template｜组合调用 CHAR + OUTFIT + STYLE + SHOT

```text
目标角色：CHAR-[角色]@版本；身份参考：R01（只负责身份与体态）
服装卡：OUTFIT-[编号]@版本；服装参考：R02（只负责裁片、材质、配件和固定点）
风格卡：STYLE-[编号]@版本；风格参考：R03（只负责线条、光照、色彩、材质表现和景深）
单图任务：SHOT-[编号]

本图动作：
神态 / 视线：
场景 / 时间 / 天气：
镜头 / 景别 / 构图：
主光源 / 补光 / 阴影：
汗水 / 水 / 泥沙 / 其他状态：
道具：
输出：单角色、单动作、单场景、独立竖幅 2:3。

先列出锁定项、应用项、单图重设计项和排除项，再给完整提示词。
一张任务只生成一张独立图；完成后检查真实输出，再更新状态。
```

## 调用规则

- CHAR 负责身份和解剖，不负责具体场景。
- OUTFIT 负责服装结构，不负责画风和镜头。
- STYLE 负责可复用画法，不自动继承原图角色、衣服或动作。
- SHOT 负责当前图的动作、神态、机位、场景和输出范围。
- 如果 STYLE 仍是草案，必须在 SHOT 中显式标记候选，不得当作已确认风格。
