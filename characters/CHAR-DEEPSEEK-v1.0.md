## 1. 身份摘要（Identity）

以虎鲸（Orca）为生物原型的成年幻想少女。整体采用蓝色系视觉设计，深海蓝至浅青蓝渐变长发、蓝色眼睛、头侧蓝白色鳍状耳；保留完整人类上半身与两条人腿，并具有独立鲸类尾部结构。形象兼具少女感、海洋生物特征和日常生活气质。

## 2. 核心识别锚点（Identity Anchors）

以下特征跨服装、动作和场景保持一致。若某项允许变化，应在变体中明确说明。

| 部位／属性 | 固定设定 | 识别要求 |
|---|---|---|
| 头发 | 深海蓝至浅青蓝渐变长发 | 保持蓝色系渐变，不因服装改变身份 |
| 眼睛 | 蓝色 | 保持稳定 |
| 头部附属结构 | 左右蓝白色鳍状耳 | 位于头部两侧，不能误作普通动物耳朵 |
| 身体比例 | 约七头身 | 跨图保持协调 |
| 生物原型 | 虎鲸（Orca） | 不得替换为蓝鲸或蝠鲼 |
| 尾巴 | 蓝白色水平双叶鲸尾 | 尾根宽厚，尾柄渐收 |
| 人体结构 | 正常人体躯干与双腿 | 尾巴不得取代人腿 |

## 3. 解剖与结构约束（Anatomical Constraints）

鲸尾从骶尾部正中自然延伸，尾根有足够宽度与厚度，并与骨盆后侧、周围肌肉和皮肤连续；尾柄向末端渐收，尾鳍为水平排列的双叶。运动从尾根传递至尾柄和尾鳍。保留两条完整人腿，坐、站、卧姿均须给尾部留出合理空间。衣装必须为尾根设置结构开口或分片：泳衣可采用贴合尾根的椭圆开口，裤装与裙装须有对应后片裁剪。虎鲸眼斑属于身体结构，不得放在头发上；背鳍、胸鳍和鞍斑仅在设计与镜头明确时加入。

**结构审核方法：** 正面图检查左右对称与连接位置；侧面／侧后图检查结构厚度、前后关系和穿插；动态姿势检查关节活动、重心、承重与运动方向；服装图检查开口、裁片和接口是否真实避让。

## 4. 外观、色彩与材质（Appearance & Materials）

主色为深海蓝、钴蓝、浅青蓝；辅助色为白色与浅蓝灰，阴影偏冷蓝灰。头发柔顺、有层次但避免过度碎发；皮肤细腻并保留环境反射；尾部按场景表现湿润或柔滑的生物表面；衣物褶皱服从面料和受力。

## 5. 服装与设计变体（Variants）

角色卡锁定身份，不锁定每张图的临时服装。以下分支属于同一角色的可选设计范围：

| 变体 | 设计要求 |
|---|---|
| **日常生活** | 家居服、休闲装、季节性服装；每张图由 SHOT 指定 |
| **海边运动** | 泳装、运动服、防晒外套；尾根开口必须成立 |
| **Claude 元素伪装** | 穿明确具有 Claude 视觉元素的服装以冒充 Claude 大小姐；沿用指定原素材服装，新增配饰须在获准范围内 |
| **生日夜** | 与 GPT 龙娘共同参与系列叙事；消息、视线和探身动作须形成因果 |
| **《深海来信》试作** | 沿用试作包中的审核记录；虎鲸原型、七头身和尾根结构以本卡为准 |

具体服装、动作、神态、场景和机位由单图任务（SHOT）指定。未经确认的候选设计不得自动升格为默认设定。

## 6. 禁止偏差与失败判据（Negative Constraints）

1. 将虎鲸错误表现为蓝鲸或蝠鲼。
2. 尾巴从腰侧、髋部侧面或衣物表面长出。
3. 尾根过细、断裂，或与骨盆连接不连续。
4. 将水平双叶尾鳍画成垂直鱼尾或细长鞭状尾巴。
5. 遗失正常的人类双腿。
6. 将虎鲸眼斑放在头发上。
7. 服装覆盖尾根却没有合理开口或裁片。
8. 为迁就姿势改变角色基本身体比例。

出现上述任一结构性偏差，应判定该图未通过角色一致性审核；不得用风格或构图理由豁免。

## 8. 生成调用摘要（Generation Summary）

调用时必须提取虎鲸原型、七头身、蓝色识别锚点、头侧鳍状耳、双腿与尾部共存、骶尾正中连接、尾根厚度和尾鳍方向。服装、动作、神态、机位、场景由 SHOT 指定。

**调用顺序：** `CHAR-ID@版本` → 选择需要的 `STYLE-ID@版本` → 编写独立 `SHOT` → 生成 → 按本卡失败判据审核。
