## 1. 身份摘要（Identity）

成年幻想少女，采用西方龙的形态语言。银白渐紫长发、紫色眼睛、西方弯角、背生蝠翼、粗壮鳞片龙尾。整体应保持少女感与轻盈气质，不能画成成熟妩媚的成人化形象；不采用东方龙或中式装饰作为默认设定。

## 2. 核心识别锚点（Identity Anchors）

以下特征跨服装、动作和场景保持一致。若某项允许变化，应在变体中明确说明。

| 部位／属性 | 固定设定 | 识别要求 |
|---|---|---|
| 头发 | 银白至浅紫渐变长发 | 保持冷色渐变 |
| 眼睛 | 紫色 | 保持稳定 |
| 角 | 西方弯角 | 弯曲方向与头骨连接自然 |
| 翅膀 | 背部蝠翼 | 翼根位于上背，具有膜翼与骨架结构 |
| 尾巴 | 粗壮鳞片龙尾 | 尾根位于骶尾部，具肌肉体积 |
| 气质 | 少女感、灵动、奇幻 | 避免成熟妩媚化 |

## 3. 解剖与结构约束（Anatomical Constraints）

蝠翼从上背肩胛区域合理连接，翼根有承重与活动空间，翼骨、翼膜和展开弧线符合西方蝠翼结构。龙尾从骶尾部延伸，尾根具有肌肉体积，逐渐过渡到尾端；鳞片方向随曲率变化。翼与尾均不得穿透躯干或衣物。服装需为翼根、肩胛活动和尾根开口留出结构空间；动作需考虑翅膀展开范围、尾部重心和站姿平衡。

**结构审核方法：** 正面图检查左右对称与连接位置；侧面／侧后图检查结构厚度、前后关系和穿插；动态姿势检查关节活动、重心、承重与运动方向；服装图检查开口、裁片和接口是否真实避让。

## 4. 外观、色彩与材质（Appearance & Materials）

默认识别色为银白、浅紫、紫色与少量金色。鳞片有方向性和体积，避免机械拼片感。皮肤、头发和翼膜的材质区分明确。

## 5. 服装与设计变体（Variants）

角色卡锁定身份，不锁定每张图的临时服装。以下分支属于同一角色的可选设计范围：

| 变体 | 设计要求 |
|---|---|
| **功能性泳装** | 深紫西方奇幻风连体泳装；贴身、稳固、便于活动和耐水；后背搭接裁片可拆卸，翼根留活动空间，尾根设独立开口；不添加长垂饰 |
| **通用浅色造型** | 白色、浅紫与金色为主，保持少女感 |
| **舞姬造型** | 按真实舞动逻辑设计上装、下装和轻纱裁片；不得将舞娘服误画成普通礼服 |
| **生日夜** | 轻盈、少女感的成年幻想造型；与鲸鱼娘同框时两者辨识度分明 |
| **星象／仪式** | 作为单图主题变体，不能反向覆盖角色身份 |

具体服装、动作、神态、场景和机位由单图任务（SHOT）指定。未经确认的候选设计不得自动升格为默认设定。

## 6. 禁止偏差与失败判据（Negative Constraints）

1. 不得改为东方龙或中式龙形。
2. 不得把蝠翼画成羽翼。
3. 翼根不得从手臂、腰侧或衣服表面突兀生长。
4. 龙尾不得从髋侧长出或与骶尾脱节。
5. 不得让衣片穿透翼膜、翼骨或尾根。
6. 泳装不得增加妨碍游动的长垂饰。
7. 避免成熟妩媚的脸部气质和体态。
8. 舞姬服不得被简化成普通晚礼服。

出现上述任一结构性偏差，应判定该图未通过角色一致性审核；不得用风格或构图理由豁免。

参考图必须标注其用途：身份、结构、服装、动作或画法。单张参考图不能自动成为所有维度的权威来源。
