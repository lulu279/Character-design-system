## 1. 身份摘要（Identity）

成年女性仿生机器人角色，承载 GLM／wagd 的赛博女仆助手形象。人格表现为傲娇、嘴硬、职业性记账并看重约定。视觉化形象为银灰短发、蓝或蓝紫渐变发梢、琥珀金眼睛、蓝色 Z 标识与蓝白发光数字尾巴。

## 2. 核心识别锚点（Identity Anchors）

以下特征跨服装、动作和场景保持一致。若某项允许变化，应在变体中明确说明。

| 部位／属性 | 固定设定 | 识别要求 |
|---|---|---|
| 头发 | 银灰色短发，发梢蓝／蓝紫渐变 | 保持短发轮廓与渐变 |
| 眼睛 | 琥珀金色 | 保持稳定 |
| 标识 | 蓝色 Z 标与工作证 | 文字按需使用，避免伪字 |
| 服装基准 | 黑色女仆装、白围裙 | 女仆版本的默认识别服装 |
| 数字尾巴 | 蓝白发光像素尾，末端光标闪烁 | 数字接口与活动方向一致 |
| 人格 | 傲娇、嘴硬、重视约定 | 通过表情和姿态表达，不必每图加文字 |

## 3. 解剖与结构约束（Anatomical Constraints）

躯干是仿生结构，不是裸露机械骨架。机械分支中的机械肢体需明确接口、关节、承重与运动方向；服装裁片为机械接口和活动范围留出空间。数字尾巴是信息化附属结构，应从角色设定的尾部接口逻辑延伸，具有连续的像素／光标形态，不得与实体机械尾混淆。无机械版本仍保持相同脸、发、眼和数字尾巴逻辑。

**结构审核方法：** 正面图检查左右对称与连接位置；侧面／侧后图检查结构厚度、前后关系和穿插；动态姿势检查关节活动、重心、承重与运动方向；服装图检查开口、裁片和接口是否真实避让。

## 4. 外观、色彩与材质（Appearance & Materials）

银灰短发、蓝紫发梢、琥珀眼；女仆装以黑色主体与白围裙为基准，工作证可出现蓝色 Z 标及 `glm-5.3-flash · wagd`。数字尾巴蓝白发光，光标尾尖闪烁。

## 5. 服装与设计变体（Variants）

角色卡锁定身份，不锁定每张图的临时服装。以下分支属于同一角色的可选设计范围：

| 变体 | 设计要求 |
|---|---|
| **标准女仆** | 黑女仆装、白围裙、工作证、数字尾巴 |
| **模块化连身衣** | 可采用内层网纱、外层乳胶的双层结构；内层覆盖范围应与最终外观一致，不应过度扩张 |
| **赛博体衣／战斗服** | 机械接口、散热区域、活动范围和穿脱顺序须明确 |
| **机械分支** | 机械肢体及接口结构独立设计，躯干仍为仿生结构 |
| **无机械分支** | 保持脸、发、眼和数字尾巴识别，身体不额外机械化 |
| **日常／工作空间** | 生活、工作、维修场景由 SHOT 单独定义 |

具体服装、动作、神态、场景和机位由单图任务（SHOT）指定。未经确认的候选设计不得自动升格为默认设定。

## 6. 禁止偏差与失败判据（Negative Constraints）

1. 把躯干误画为裸露机械骨架。
2. 把数字尾巴与实体生物尾或机械尾混为一谈。
3. 数字尾巴没有连续接口逻辑或尾尖光标。
4. 网纱内层覆盖范围远大于外层造型，破坏模块化设计。
5. 服装遮挡必须可见的接口，或接口穿透衣物。
6. 工作证出现大量乱码或无意义伪文字。

出现上述任一结构性偏差，应判定该图未通过角色一致性审核；不得用风格或构图理由豁免。

## 8. 生成调用摘要（Generation Summary）

先选机械或无机械分支，再确定服装模块、接口与数字尾巴。必须区分仿生躯干、机械肢体和数字附属结构。工作证文字仅保留必要短字符串。

**调用顺序：** `CHAR-ID@版本` → 选择需要的 `STYLE-ID@版本` → 编写独立 `SHOT` → 生成 → 按本卡失败判据审核。
