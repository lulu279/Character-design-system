# 幻术师 Mesmer／Tiamat · IO｜角色卡

## 0. 基本信息

| 字段 | 内容 |
|---|---|
| 资产 ID | `CHAR-MESMER` |
| 版本 | v1.0 |
| 类型 | 《暗黑地牢》MOD 角色二创补充设定 |
| 状态 | 设计基准已整理；遮挡部位与皮肤差异待原始素材复核 |
| 适用范围 | 原作形象补充、侧后视图、技能主题插画、哥特风格变体 |

**来源优先级**

1. 用户明确确认的身份、结构与硬约束。
2. 用户指定的原作、社区参考或源素材。
3. 已审核通过的角色基准图与结构设定图。
4. 历史生成稿、候选设计与未确认推断。

低优先级资料不得覆盖高优先级设定。事实、确认项、推断和待核内容必须明确区分。

## 1. 身份摘要（Identity）

基于《暗黑地牢》MOD 中 Mesmer／Tiamat · IO 的角色形象进行补充设定。以用户提供的原作图为主要轮廓依据；头像、待机、动作和技能 Sprite 用于补充可见细节。

## 2. 核心识别锚点（Identity Anchors）

以下特征跨服装、动作和场景保持一致。若某项允许变化，应在变体中明确说明。

| 部位／属性 | 固定设定 | 识别要求 |
|---|---|---|
| 头发 | 银白长发 | 发型轮廓以原作素材为准 |
| 头饰 | 黑色发链、小冠饰与紫红宝石 | 固定方式需在侧后图中说明 |
| 颈部 | 高领颈饰 | 与胸腹服装连续 |
| 躯干服装 | 胸腹交叉绑带 | 交叉方向和固定点清楚 |
| 外层 | 黑紫宽袖披挂、洋红内衬 | 宽袖与肩部连接关系明确 |
| 下装 | 不对称裙片、深色长袜浅色纹样 | 前后片关系需复核 |

## 3. 解剖与结构约束（Anatomical Constraints）

优先确保头饰、颈饰、肩部、宽袖、裙片和袜装之间的连接关系。侧后视图必须交代冠饰固定、宽袖连接、披挂与裙片前后对应。原素材遮挡的背部裁片、扣件与袜纹不得凭空定为原作事实，应标注为待核或同人补充。翅翼、巨冠和魔印若加入，必须有明确的来源或作为用户批准的变体。

**结构审核方法：** 正面图检查左右对称与连接位置；侧面／侧后图检查结构厚度、前后关系和穿插；动态姿势检查关节活动、重心、承重与运动方向；服装图检查开口、裁片和接口是否真实避让。

## 4. 外观、色彩与材质（Appearance & Materials）

主要识别色为银白、黑、深紫与洋红，宝石使用紫红色。材质区分金属、软布、皮革和宝石；原作轮廓优先于后续画风变化。

## 5. 服装与设计变体（Variants）

角色卡锁定身份，不锁定每张图的临时服装。以下分支属于同一角色的可选设计范围：

| 变体 | 设计要求 |
|---|---|
| **原装基准** | 遵循用户提供的原作图与 MOD 素材 |
| **哥特萝莉回调** | 作为可选同人服装与画法分支，不覆盖原装基准 |
| **技能主题** | Mirror、Time Warp、Gravity Well、Five Signets 等按对应 Sprite 取证 |
| **女皇／仪式主题** | 仅在用户指定时采用；暗紫环境、镜面折射或银辉仪式光属于画面方案 |

具体服装、动作、神态、场景和机位由单图任务（SHOT）指定。未经确认的候选设计不得自动升格为默认设定。

## 6. 禁止偏差与失败判据（Negative Constraints）

1. 把不同皮肤 Mesmer_B 与 Mesmer_C 混为同一套服装事实。
2. 将被遮挡的背部结构、扣件或袜纹当作已证实原作细节。
3. 用画风迁移覆盖原装服装。
4. 侧后视图中头饰、宽袖或裙片连接关系断裂。
5. 无依据增加翅翼、巨冠或多重魔印。

出现上述任一结构性偏差，应判定该图未通过角色一致性审核；不得用风格或构图理由豁免。

## 7. 参考资产与证据等级（References）

用户上传的原作图用于主要轮廓；头像、待机、动作与技能 Sprite 用于具体可见信息；Mesmer_B 与 Mesmer_C 分别标记。MOD 原始压缩包仅作私人形象参考。

参考图必须标注其用途：身份、结构、服装、动作或画法。单张参考图不能自动成为所有维度的权威来源。

## 8. 生成调用摘要（Generation Summary）

每次引用素材时注明其角色皮肤与用途。先确定原装基准，再指定是否采用哥特萝莉或技能主题变体。对遮挡信息保留不确定性。

**调用顺序：** `CHAR-ID@版本` → 选择需要的 `STYLE-ID@版本` → 编写独立 `SHOT` → 生成 → 按本卡失败判据审核。
