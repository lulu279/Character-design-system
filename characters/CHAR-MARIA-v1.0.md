## 1. 身份摘要（Identity）

以《少女前线2：追放》破坏者（Destroyer／玛利亚）为对象的二创设定。核心辨识点是仿生大腿与膝下外露机械结构的组合，以及双肩外露。

## 2. 核心识别锚点（Identity Anchors）

以下特征跨服装、动作和场景保持一致。若某项允许变化，应在变体中明确说明。

| 部位／属性 | 固定设定 | 识别要求 |
|---|---|---|
| 大腿 | 仿生皮肤／仿生结构 | 不是整条金属义肢 |
| 膝盖以下 | 外露机械小腿与足部 | 机械结构必须清晰可见 |
| 肩部 | 双肩外露 | 不得被衣物覆盖 |
| 关节 | 膝部机械边界与转轴 | 明确前后方向、承重和活动关系 |

## 3. 解剖与结构约束（Anatomical Constraints）

大腿部分为仿生皮肤或仿生结构；从膝盖及膝盖以下才是外露机械小腿与足部。膝部需要表现仿生与机械的连接边界、转轴和承重方向。双肩必须外露。动态动作应检查膝关节弯曲、足底接触、重心和落脚方向；机械结构不得穿过衣物或人体。

**结构审核方法：** 正面图检查左右对称与连接位置；侧面／侧后图检查结构厚度、前后关系和穿插；动态姿势检查关节活动、重心、承重与运动方向；服装图检查开口、裁片和接口是否真实避让。

## 4. 外观、色彩与材质（Appearance & Materials）

外观以原作及用户已采纳的参考素材为准。大腿仿生材质与膝下机械材质应有清楚区别；金属件需表现结构层级、关节和受力方向。

## 5. 服装与设计变体（Variants）

角色卡锁定身份，不锁定每张图的临时服装。以下分支属于同一角色的可选设计范围：

| 变体 | 设计要求 |
|---|---|
| **原版基准** | 以原作与已审核参考为准 |
| **服装变化** | 允许大胆更换衣装，但双肩和膝下机械结构必须外露 |
| **动作变化** | 通过手部任务、视线、支撑腿和镜头距离形成差异 |
| **结构展示** | 可单独放大膝部、机械小腿与足部连接 |

具体服装、动作、神态、场景和机位由单图任务（SHOT）指定。未经确认的候选设计不得自动升格为默认设定。

## 6. 禁止偏差与失败判据（Negative Constraints）

1. 将整条腿从髋部起都画成金属义肢。
2. 用长裤、丝袜、袜子、布料或裙摆遮住膝下机械结构。
3. 遮住双肩。
4. 机械膝关节缺少转轴或连接边界。
5. 机械足部落地角度与重心不匹配。
6. 衣物或机械件互相穿模。

出现上述任一结构性偏差，应判定该图未通过角色一致性审核；不得用风格或构图理由豁免。

参考图必须标注其用途：身份、结构、服装、动作或画法。单张参考图不能自动成为所有维度的权威来源。
