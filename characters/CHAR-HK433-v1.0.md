## 1. 身份摘要（Identity）

以《少女前线》中的 HK433 为对象的角色设计。银白长发、高马尾、侧编发、黄绿色眼睛；佩戴黑色猫耳轮廓战术耳机与颈部呼吸防护装置。即使更换服装，也应一眼识别为同一角色。

## 2. 核心识别锚点（Identity Anchors）

以下特征跨服装、动作和场景保持一致。若某项允许变化，应在变体中明确说明。

| 部位／属性 | 固定设定 | 识别要求 |
|---|---|---|
| 头发 | 银白长发、高马尾、侧编发 | 发型轮廓稳定 |
| 眼睛 | 黄绿色 | 保持稳定 |
| 耳机 | 黑色猫耳轮廓战术耳机 | 猫耳为设备外形，不是生物耳朵 |
| 呼吸器 | 颈部呼吸防护装置 | 佩戴位置固定，衣领须留空间 |
| 装备逻辑 | 枪械、挂载与防护设备 | 固定点和受力关系一致 |

## 3. 解剖与结构约束（Anatomical Constraints）

耳机由头梁与外壳构成，猫耳轮廓属于设备外形；必须贴合头部，不得悬浮。呼吸装置位于颈部，衣领不得遮断或穿模。枪械与挂载应符合握持、背负和重心逻辑；肩带、枪带、弹匣袋等装备要有明确固定点。正侧背视图保持相同尺度、地平线和装备位置。

**结构审核方法：** 正面图检查左右对称与连接位置；侧面／侧后图检查结构厚度、前后关系和穿插；动态姿势检查关节活动、重心、承重与运动方向；服装图检查开口、裁片和接口是否真实避让。

## 4. 外观、色彩与材质（Appearance & Materials）

默认战术配色以黑、白、灰为主，少量暗红作为内衬或识别色。银白头发、黄绿色眼睛、猫耳轮廓耳机与颈部呼吸器是优先识别元素。

## 5. 服装与设计变体（Variants）

角色卡锁定身份，不锁定每张图的临时服装。以下分支属于同一角色的可选设计范围：

| 变体 | 设计要求 |
|---|---|
| **01 标准三视图** | 同一默认装束、同尺度、同地平线，确认装备佩戴关系 |
| **02 默认战术形象** | 黑白灰与少量暗红；独立全身立绘 |
| **03 城市特战** | 深色防护、功能挂载、城市雨夜 |
| **04 格里芬副官** | 黑修身外套、白衬衫、高腰短裙、暗红内衬、银肩章；文件夹与指挥桌 |
| **05 休假日常** | 浅色针织与简洁下装；保留黑丝袜或过膝袜 |
| **06 冬季野战** | 白灰伪装、冬季分层、手套长靴、护膝、雪地挂载；持 HK433 |
| **07 正式礼装** | 黑白深灰、克制红色内衬或披风；军礼剪裁，保留耳机和呼吸器 |

具体服装、动作、神态、场景和机位由单图任务（SHOT）指定。未经确认的候选设计不得自动升格为默认设定。

## 6. 禁止偏差与失败判据（Negative Constraints）

1. 耳机猫耳被误画成真实动物耳朵。
2. 呼吸器从颈部移位或被衣领无故吞没。
3. 银白长发、高马尾或侧编发被无故改变。
4. 枪械握持方向、枪带和装备固定关系不合理。
5. 不同视图中装备位置与比例不一致。
6. 礼装或休假装导致角色识别锚点丢失。

出现上述任一结构性偏差，应判定该图未通过角色一致性审核；不得用风格或构图理由豁免。

## 8. 生成调用摘要（Generation Summary）

先锁定脸、发型、耳机和颈部呼吸器，再按图号选择服装。每张独立插画另写 SHOT；参考图须明确指定用途（脸、服装、装备或画法）。

**调用顺序：** `CHAR-ID@版本` → 选择需要的 `STYLE-ID@版本` → 编写独立 `SHOT` → 生成 → 按本卡失败判据审核。
