# TEMPLATE-SHOT-SCENE｜单图场景任务卡

**SHOT ID：** `SHOT-...`  
**角色卡：** `CHAR-...@v...`  
**服装卡：** `CHAR-OUT-...@v...`  
**风格卡 / 光照模块：** `STYLE-...@v...`（若为草案需标明）  
**输出：** 1 张独立图 / 画幅 / 方向

## 1. 本图目标

一句话描述画面叙事与需要验证的内容。

## 2. 场景

地点、季节、时间、天气、背景结构、前中后景。

## 3. 动作与受力

身体朝向、重心、承重点、手脚与道具接触、衣发受力、附加结构运动。

## 4. 神态与视线

表情物理线索、情绪方向、视线目标。角色不必看镜头。

## 5. 机位与构图

景别、视角、相机高度、透视、裁切、主体位置、留白。

## 6. 光源与明暗

- 主光源位置 / 方向 / 色温：
- 补光来源 / 强度：
- 投影方向 / 接触阴影：
- 反射 / 局部高光：
- 暗部保留：

## 7. 材质与状态

汗水、雨水、泥沙、灰尘、蒸汽、湿发、布料磨损等。说明分布位置，不要笼统写“很脏”或“很湿”。

## 8. 道具与背景限制

只列对动作和叙事有用的道具；明确哪些装饰不需要。

## 9. 单图提示词

```text
[完整提示词：一个角色、一个动作、一个连续场景]
```

## 10. 验收清单

- [ ] 服装与指定卡片一致。
- [ ] 身份与附加结构正确。
- [ ] 光源位置和投影一致。
- [ ] 动作受力与道具接触合理。
- [ ] 背景没有无关堆叠。
- [ ] 是一张独立图，不是拼图 / 分栏 / 接触表。
- [ ] 状态按 draft / candidate / validated_single_image 标记。
