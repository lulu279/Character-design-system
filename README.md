# Character Design System — Cards Pack v2.0

本包是角色卡与风格卡的轻量整理版，供 ChatGPT 对话创作和后续仓库维护使用。

## 内容

- `characters/`：6 张角色卡。
- `styles/`：7 张风格卡。
- `references/`：与风格卡配套的 7 张参考图。
- `templates/`：角色卡、风格卡和 SHOT 单图任务模板；`docs/`：写作规范与资产索引。
- `examples/`：调用示例；`prompts/`、`workflow/`：历史资产，保留。

## 角色与风格的调用边界

`CHAR` 管身份、比例、解剖、识别锚点与服装变体；`STYLE` 管线条、光影、色彩、材质和景深；`SHOT` 管当前这张图的服装、动作、神态、机位、场景、构图和输出范围。STYLE 不得覆盖 CHAR。

## 快速调用

1. 选择角色卡，例如 `CHAR-DEEPSEEK@v1.0`。
2. 选择风格卡，例如 `STYLE-WARM-WINDOW@v1.0`。
3. 为本次图片单独填写 `SHOT` 模板。
4. 逐张指定参考图用途。
5. 生成后按角色卡的结构硬约束和风格卡的偏离判据审核。

## 重要说明

- 旧版卡片中的 ID、版本和确认状态予以保留；本包对结构和表达进行统一，不代表所有旧图均通过审核。
- `styles/` 中 `STYLE-BIRTHDAY-NIGHT` 与 `STYLE-DEEPSEA-LETTERS` 所附为项目内验证／候选图，不是原始风格来源，卡内已明确标注。
- 参考图的作者、原帖或许可未知时，按私人参考资料处理；本包不声称拥有第三方原图版权。
- 本包不包含大量历史生成稿、MOD 原始压缩包或第三方素材全集。
