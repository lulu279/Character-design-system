# STYLE-NOON-COASTAL-DIRECTIONAL｜正午海滨方向性日光

**版本：** v0.1 草案  
**状态：** `draft_pending_user_confirmation`  
**类型：** 户外运动场景光照模块候选

## 1. 核心画法

以正午太阳作为明确方向性的主光源。保持阳光方向、人物投影和地面接触阴影一致；海面与天空提供较弱的冷色反射补光，但不抹平主光方向。

## 2. 光源关系

- **主光：** 高角度正午日光，方向明确，形成肩部、头发、帽檐、腿部和岩石的受光面。
- **投影：** 由人物、帽檐、尾巴和岩石产生方向一致的投影；接触阴影必须落在真实接触位置。
- **环境补光：** 海面反射提供冷蓝 / 青蓝补光，天空提供柔和填充；两者不能变成第二个同强度主光。
- **高光：** 汗水、水珠和湿岩仅在受光角度出现局部高光。

## 3. 稳定提示词

```text
正午海滨环境，使用高角度且方向明确的太阳作为主光源。人物和岩石具有清楚的方向性明暗分区与接触阴影。海面反射和天空散射仅提供较弱的冷色补光，不要把画面照成均匀、平行、无方向的光场。保留皮肤、湿发、汗水和水珠的局部高光，避免夕阳橙金色调。
```

## 4. 偏离判据

1. 画面色调变成夕阳 / 黄金时刻。
2. 人物没有明确投影，像被均匀棚灯照亮。
3. 海面补光强到抹掉太阳方向。
4. 皮肤和衣服整体被过曝，失去体积。

## 5. 归档说明

用户明确要求户外运动场景调回正午，并指出不要均匀平行光。该规则可直接作为本系列 SHOT 约束；是否升格为跨项目 STYLE 卡，仍待用户确认。
