# STYLE-LANTERN-POINT-LIGHT｜煤油灯局部点光源夜景

**版本：** v0.1 草案  
**状态：** `draft_pending_user_confirmation`  
**类型：** 可复用光照模块候选；目前首先服务于 DeepSeek 夜海捕鱼 / 海屋烹饪场景。

## 1. 核心画法

夜景以靠近人物的煤油灯作为主要暖色点光源。灯具必须在画面内或有明确空间位置；光照从灯具向外衰减，形成局部照明池，而不是整幅画均匀发亮。

## 2. 光源关系

- **主光：** 近景煤油灯，暖琥珀色，照亮人物靠近灯的一侧、湿发、水珠、鱼鳞、手部和近处岩石 / 木桌。
- **环境补光：** 窗外月光或夜空冷蓝环境光，强度较低，只用于分离轮廓和保留暗部结构。
- **局部次光：** 烹饪时炉火可对锅底、手和下半身提供局部橙色补光；不得取代煤油灯成为全场泛光。
- **阴影：** 灯具背光侧保留深蓝灰阴影，细节可见但不被均匀提亮。

## 3. 材质反应

水面、湿岩、鱼鳞、玻璃灯罩、金属锅具和皮肤水珠只在符合几何关系的位置出现局部高光。蒸汽在灯光附近可见，远处逐渐融入暗部。

## 4. 稳定提示词

```text
深夜低照度环境，以画面近处一盏可见的煤油灯作为唯一主要暖色点光源。灯光在人物、湿岩、水面和鱼鳞上形成局部琥珀色高光，离灯越远迅速衰减。窗外冷蓝月光仅作为弱环境补光和轮廓分离。暗部保留蓝灰层次，不使用均匀平行光，不把整幅画照亮。若有炉火，只作为烹饪区域的局部次光源。
```

## 5. 偏离判据

1. 画面没有可定位的煤油灯，却出现大面积暖光。
2. 人物、背景和远处物体亮度几乎相同。
3. 所有阴影被均匀抬亮，缺少光照衰减。
4. 多个不合理光源造成相互冲突的投影。
5. 辉光遮盖人物和道具细节。
