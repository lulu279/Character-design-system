# Publication and Reference Policy

1. Keep user-supplied reference images separate from generated project examples.
2. The user's current DeepSeek outfit references and the original upstream character imagery should be treated as private reference material until their source and permitted use are confirmed.
3. The project README already states that references with unknown authorship / source / licence are private references and that the project does not claim third-party rights.
4. Do not commit superseded drafts or review-only composites as canonical assets.
5. A generated derivative illustration does not by itself settle the licensing of the upstream character identity or brand. Keep the project's upstream / derivative / newly designed asset distinctions intact.
6. Public repository additions should prioritize text cards, prompt modules, and only those generated examples the user has chosen to publish.
