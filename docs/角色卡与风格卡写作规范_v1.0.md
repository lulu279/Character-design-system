# 角色卡与风格卡写作规范（独立规范文件）

- 规范 ID：`CARD-WRITING-RULES`
- 版本：v1.0
- 状态：当前项目采用

## 1. 通用元数据

每张卡必须包含唯一 ID、版本、类型、状态、适用范围和来源／证据说明。状态至少区分：待整理、待确认、已确认、已归档、历史／停用。不得把草案伪装成已确认资产。

## 2. 证据分级

关键内容须明确属于以下哪一类：

1. **原作事实／来源可见**：原作或指定参考素材中直接可见。
2. **用户确认**：用户明确要求或纠正并确认。
3. **合理推断**：为补足结构或逻辑提出，但尚未被用户确认。
4. **未确认／待核**：来源遮挡、信息不足或存在冲突。

低等级证据不得覆盖高等级确认。不同角色皮肤、不同参考图和不同用途必须分开标记。

## 3. 角色卡 CHAR 的边界

角色卡只管理身份与跨图稳定事实：身份摘要、识别锚点、身体比例、解剖与附加结构、外观材质、服装变体范围、禁止偏差、参考资产、生成摘要和版本历史。

角色卡不应永久写入某张图的具体动作、表情、镜头、背景、构图或临时服装组合。此类信息属于 SHOT。

### 解剖与结构硬约束

对尾、翼、鳍、机械肢体等附加结构，必须描述：连接位置、结构连续性、关节／骨架／肌肉或机械接口、承重与运动方向、重心和平衡、服装空间关系及开口／裁片。每项硬约束必须有可观察的失败判据。

## 4. 风格卡 STYLE 的边界

风格卡只管理可复用画法：线条与边缘、光源方向、明暗层级、色彩、材质、背景与景深、稳定提示词、偏离判据。

每张风格卡必须内嵌一张参考图，采用 Markdown 相对路径引用；图片文件必须随卡片一起归档。若参考图是项目验证图而非原始来源，必须明确标注，不得混淆来源。

### 迁移范围

- **默认迁移**：用户已确认可以独立复用的画法特征。
- **可选迁移**：服装模板、表情、动作、镜头、场景等，必须在单图任务中明确选择。
- **明确排除**：原图角色身份、五官、体态、专属服装和特定构图等不应自动继承的内容。

除非用户明确确认，不得把某张参考图的全部视觉内容都归入风格卡。

## 5. 单图任务 SHOT 的边界

每次单图生成单独建立任务记录，至少写明：目标角色卡及版本、风格卡及版本、参考图各自用途、服装、动作、神态、机位、场景、构图、输出范围和审核重点。多张参考图必须逐张指定用途，例如 R01 管脸与发型，R02 管服装，R03 管画法。

## 6. 提示词组织顺序

1. 角色身份与识别锚点（CHAR）。
2. 结构／解剖硬约束（CHAR）。
3. 画法核心（STYLE）。
4. 本图服装、动作、表情、场景、机位和构图（SHOT）。
5. 负面约束与失败判据。

STYLE 不得覆盖 CHAR；SHOT 可以改变单图呈现，但若触及身份锁或结构锁，必须先判断是否属于明确的角色变体或角色升版。

## 7. 更新与版本管理

每次更新必须记录修改原因、确认依据、影响范围、旧版与新版差异，以及使用该版本的验证图。不得覆盖历史确认内容。只调整单图时更新 SHOT，不升级 CHAR／STYLE。

## 8. 交付审核

- 卡片 ID 唯一，版本与状态完整。
- 每个关键特征可观察、可执行。
- 原作事实、用户确认、推断、待核项分开。
- CHAR 与 STYLE 可独立读取、独立调用。
- 每张 STYLE 均有一张随包参考图，路径有效。
- 每个结构硬约束都有失败判据。
- 每次单图任务均独立记录 SHOT。
- ZIP 解压后相对链接仍有效；不夹带未经要求的大量原始图稿或第三方原始素材包。
