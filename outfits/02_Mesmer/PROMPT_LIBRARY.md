# Mesmer / Tiamat · IO｜详细服装提示词

## 全局证据锁
服装以指定原作插画和MOD皮肤Sprite为依据。保留银白长发、黑色发链、小冠饰、紫红宝石、高领颈饰、胸腹交叉绑带、黑紫宽袖、洋红内衬披挂、不对称裙片和深色长袜浅色纹样。不同皮肤、Portrait、动作帧和技能Sprite分别核对，不混用。未展示的背面固定方式标记为待核，不无依据添加翅翼或巨冠。

## MES-00 原作基础衣装
沿用指定皮肤中可见的黑紫色衣装。上身为贴合躯干的黑色主体，胸腹区域有交叉绑带，绑带形成明确斜向路径并连接腰部固定点；颈部为高领颈饰，配黑色链饰和紫红宝石。袖装采用黑紫宽袖，袖口较宽，动作时形成有重量的垂坠褶；披挂内侧为洋红色，外侧保持深色。下摆采用不对称裙片，前后片长度和开合方向依指定皮肤参考。腿部搭配深色长袜，表面有浅色纹样。头部保留黑色发链、小冠饰与紫红宝石。背景简洁偏暗，柔和侧光，重点表现衣装层级。

## MES-01 哥特萝莉风回调（候选）
保持Mesmer原有银白长发、黑紫色块、紫红宝石和衣装主要轮廓，探索更精致的哥特萝莉呈现：高领颈饰、克制蕾丝收边、层叠裙片、袖口薄纱和小面积暗红宝石。优先改变面料渲染、线条精度、光影和整体气氛，不擅自把宽袖替换成泡袖，也不凭空添加大面积裙撑、翅翼或巨冠。真正的衣装变体必须单独标记新增裁片。

## MES-02 侧后方衣装结构图
斜后方全身机位，角色轻轻回头，近侧脚承重。画面清楚呈现黑紫宽袖如何连接上臂、洋红内衬如何从披挂边缘露出、不对称裙片如何覆盖腰臀，以及胸腹交叉绑带如何绕向背部。只描绘参考能够支持的结构；若背面扣件、肩带交叉或披挂锚点在原作素材中不可见，则标为“同人补全结构”，不冒充原作。衣料有合理重量，袖子和披挂随姿态产生不同方向的摆动。
