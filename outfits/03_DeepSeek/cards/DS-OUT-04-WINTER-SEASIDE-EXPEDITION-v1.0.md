# DS-OUT-04｜冬季雪海远征装

**角色：** DeepSeek 鲸鱼娘  
**季节：** 冬季  
**版本：** v1.0  
**状态：** `design_defined_pending_validation`  
**定位：** 适用于雪地、冰冷海岸和寒冷天气的户外活动。以白色、藏蓝和冰蓝构建明显的保暖层级，整体廓形厚实。

## 1. 设计概念
适用于雪地、冰冷海岸和寒冷天气的户外活动。以白色、藏蓝和冰蓝构建明显的保暖层级，整体廓形厚实。。本卡用于固定衣装结构；具体动作、机位、表情和环境仍由单张 SHOT 指定。

## 2. 服装层级与部件
### 外层：白色中长保暖防风外套
中长款；独立帽兜；帽缘可用浅蓝保暖绒面；双向防水拉链；肩部和胸部深蓝拼接；两侧保暖插袋；袖口弹性收束与魔术贴；内部保温填充。

### 中层：深蓝高领保暖衣
长袖、高领、合体但不紧绷；保暖针织面料；领口少量浅蓝细节。

### 下装：深蓝加绒长裤
中高腰；直筒或微收口；膝部立体活动裁片；内层抓绒、外层防风防水；腰部弹性调节。

### 鞋履
中高帮防水雪地靴；保暖内衬；防滑鞋底；白蓝拼色；鞋口可收紧。

### 配件
蓝白围巾、保暖手套、护耳帽 / 保暖帽、雪地护目镜、小型远征背包、保温水壶。

## 3. 配色与材料
| 部件 | 色彩 | 材料 / 表面 |
|---|---|---|
| 外套 | 雪白 / 藏蓝 | 防风防水面料、保温填充 |
| 内搭 | 深海蓝 | 保暖针织 |
| 长裤 | 深蓝 | 加绒防风布 |
| 鞋履 | 白 / 蓝 | 防水复合材料 |
| 配件 | 冰蓝 / 白 | 保暖织物 |

## 4. 尾根与结构适配
外套后腰采用尾根专用弧形分割；开口边缘使用柔软保暖包边。可选配可拆卸尾鳍保护套，但不得限制尾巴摆动。长裤后腰开口必须与尾根位置一致。

## 5. 动作与穿着适配
适合雪地行走、蹲下检查装备、坐在岩石上保温休息。厚手套应能抓握水壶和背包扣；雪地靴与地面接触需要明确防滑结构。

## 6. 推荐场景
- 雪覆海岸
- 冬季灯塔
- 冰雪港口
- 雪地露营
- 暴雪远征
- 极光下的夜间休息


## 8. 禁止偏差
1. 不要将冬装画成夏季短外套加围巾。
2. 不要使用高跟鞋或不防滑鞋底。
3. 尾根附近不能堆积过厚填充层。
4. 不能把尾鳍固定成不能摆动的形态。

## 9. 备注与待验证项
现有冬季设计板包含尾鳍保暖保护套的可选构想；该部件仍属于候选配件，尚未验证实际活动范围。
