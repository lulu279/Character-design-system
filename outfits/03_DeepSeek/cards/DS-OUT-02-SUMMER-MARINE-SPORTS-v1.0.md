# DS-OUT-02｜夏季海滨运动装

**角色：** DeepSeek 鲸鱼娘  
**季节：** 夏季  
**版本：** v1.0  
**状态：** `reference_locked_design_defined_pending_validation`  
**定位：** 以用户提供的全身海滨运动装参考图为基准。轻便、透气、防晒、速干，适合海滨旅行、礁石探索、潮池观察和运动后休息。

## 1. 设计概念
以用户提供的全身海滨运动装参考图为基准。轻便、透气、防晒、速干，适合海滨旅行、礁石探索、潮池观察和运动后休息。。本卡用于固定衣装结构；具体动作、机位、表情和环境仍由单张 SHOT 指定。

## 2. 服装层级与部件
### 遮阳帽
白色运动帽，帽檐有自然弧度，前方蓝色鲸鱼标志；后部可调节搭扣；帽侧可固定蓝白花饰 / 发带。

### 可脱卸外套
浅灰白短款轻薄连帽外套；短袖或落肩短袖结构；局部半透明透气网布；双向拉链；弹性下摆；胸部小型 DeepSeek / 鲸鱼标志。外套可以穿着、敞开或脱下携带。

### 运动上衣
白色合体速干运动上衣，蓝色滚边，胸前鲸鱼图案；侧腰采用蓝色弧形拼接；不采用蕾丝或束身胸衣结构。

### 功能短裤
浅灰白运动短裤，蓝色包边；中高腰；深蓝功能腰带与金属扣；两侧立体口袋；外层不对称裙片式装饰，但主体必须仍是完整运动短裤；内层可有独立安全短裤。

### 鞋履与配件
蓝白厚底运动凉鞋，宽幅固定带和防滑鞋底；深蓝小型斜挎包；蓝色腕表、手环、水壶和小型鲸鱼挂件。

## 3. 配色与材料
| 部件 | 色彩 | 材料 / 表面 |
|---|---|---|
| 帽子 | 白 / 鲸鱼蓝 | 速干织物 |
| 外套 | 浅灰白 / 蓝 | 轻量尼龙、透气网布 |
| 运动上衣 | 白 / 群青 | 弹性速干布 |
| 短裤 | 浅灰白 / 蓝 | 弹性运动布 |
| 腰带 | 深海蓝 | 尼龙织带与金属扣 |
| 鞋履 | 白 / 蓝 | 合成材料、防滑橡胶 |

## 4. 尾根与结构适配
短裤后腰中央设置尾根专用弧形开口，开口对齐骶尾部正中；腰带在尾根左右两侧保持稳定固定。尾巴从开口自然延伸，不从髋侧出现。外套后摆不能压迫尾根。

## 5. 动作与穿着适配
适合正午步行、跑动、蹲下拾贝、攀爬低矮礁石、在遮阳亭饮水。帽檐、长发和外套下摆受海风影响；凉鞋必须有脚背和脚踝固定。

## 6. 推荐场景
- 正午海滨步道
- 潮池观察
- 海岸礁石攀爬
- 遮阳亭饮水休息
- 海滨咖啡馆

## 8. 禁止偏差
1. 不要改成普通泳装或女仆装。
2. 不要增加蕾丝、吊袜带、胸衣式结构。
3. 短裤不能变成只有裙片的装饰而失去运动短裤主体。
4. 尾巴不得从侧腰或髋侧伸出。

## 9. 备注与待验证项
用户提供的全身海滨运动参考图是本卡的最高优先级服装依据。外套可按活动状态脱下，但内搭、短裤和配件体系保持一致。
