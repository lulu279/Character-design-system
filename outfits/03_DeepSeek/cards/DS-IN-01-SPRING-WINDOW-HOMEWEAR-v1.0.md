# DS-IN-01｜春季窗边薄衫

**角色：** DeepSeek 鲸鱼娘  
**季节：** 春季室内  
**版本：** v1.0  
**状态：** `design_defined_pending_validation`  
**定位：** 春季居家轻叠穿。清爽、柔软、日常，不带女仆或束身服装语言。

## 1. 设计概念
春季居家轻叠穿。清爽、柔软、日常，不带女仆或束身服装语言。。本卡用于固定衣装结构；具体动作、机位、表情和环境仍由单张 SHOT 指定。

## 2. 服装层级与部件
### 内层衬衫
白色棉质宽松衬衫；小翻领；普通纽扣前襟；长袖可自然卷起；肩部略落肩；圆弧下摆覆盖腰部。

### 外层开衫
浅蓝色薄针织开衫；略宽松；自然 V 领；小纽扣前襟；宽松长袖；细罗纹袖口与下摆；可敞开穿着。

### 下装
浅灰蓝或奶白棉质居家短裤；中高腰松紧腰头；抽绳；两侧插袋；大腿上段至中段长度。

### 袜鞋配件
白色短棉袜、软底浅蓝室内拖鞋；简单蓝色发夹或小型鲸鱼吊坠。

## 3. 配色与材料
| 部件 | 色彩 | 材料 / 表面 |
|---|---|---|
| 衬衫 | 纯白 | 柔软棉布 |
| 开衫 | 浅蓝 | 薄棉针织 |
| 短裤 | 奶白 / 灰蓝 | 棉质弹性布 |
| 袜子 | 白色 | 棉纱 |
| 拖鞋 | 浅蓝 | 柔软织物 |

## 4. 尾根与结构适配
衬衫后下摆和开衫后腰采用中央柔性分割；短裤后腰设置骶尾部正中尾根开口，边缘使用柔软包边，不加硬扣件。

## 5. 动作与穿着适配
适合坐姿阅读、伸手浇花、整理房间和窗边休息。开衫袖口应允许卷起，短裤与尾巴不能在坐姿时相互穿插。

## 6. 推荐场景
- 春日晨起
- 窗边阅读
- 给植物浇水
- 整理房间
- 午后休息

## 7. 可复用提示词块
```text
DeepSeek 鲸鱼娘穿白色棉质宽松衬衫，外搭浅蓝薄针织开衫，下身为浅灰蓝棉质居家短裤，搭配白色短棉袜和软底拖鞋。普通、舒适、自然的春季家居服。
```

## 8. 禁止偏差
1. 不添加女仆头饰、围裙或蓬蓬袖。
2. 不添加蕾丝胸衣或吊袜带。
3. 不要过度装饰房间。
4. 尾根必须有专用开口。
