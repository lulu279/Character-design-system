# DS-IN-02｜夏季白色棉T

**角色：** DeepSeek 鲸鱼娘  
**季节：** 夏季室内  
**版本：** v1.0  
**状态：** `design_defined_pending_validation`  
**定位：** 极简清凉的夏季居家服。以宽松白色棉 T 和深海蓝居家短裤构成，不添加内衣化或女仆元素。

## 1. 设计概念
极简清凉的夏季居家服。以宽松白色棉 T 和深海蓝居家短裤构成，不添加内衣化或女仆元素。。本卡用于固定衣装结构；具体动作、机位、表情和环境仍由单张 SHOT 指定。

## 2. 服装层级与部件
### 上装
宽松白色棉质 T 恤；自然落肩；圆领；短袖至上臂中段；领口和袖口浅蓝色窄包边；胸前一个小型蓝色鲸鱼图案；衣长覆盖腰部和部分髋部。

### 下装
深海蓝居家运动短裤；中高腰或自然低腰均可按单图指定；弹性腰头与抽绳；两侧插袋；宽松裤腿；长度覆盖大腿上段至中段；侧边可有小开衩。

### 袜鞋配件
可赤脚或白色短袜；浅蓝室内拖鞋；只保留简单发夹或发圈。

## 3. 配色与材料
| 部件 | 色彩 | 材料 / 表面 |
|---|---|---|
| T恤 | 白色 | 中等厚度纯棉针织 |
| 包边 | 浅蓝 | 弹性织带 |
| 短裤 | 深海蓝 | 棉质混纺 / 透气运动针织 |
| 袜子 | 白色 | 棉纱 |
| 拖鞋 | 浅蓝 | 软质织物 |

## 4. 尾根与结构适配
T 恤后下摆与短裤后腰均需为尾根设置柔性中央开口；开口围绕骶尾部正中，不让数字化或生物尾部穿过完整布料。

## 5. 动作与穿着适配
适合午睡、阅读、看电影、厨房准备饮料、阳台吹风。T 恤在伸手和坐下时保持自然宽松，不需要固定看镜头。

## 6. 推荐场景
- 夏日卧室
- 空调房阅读
- 沙发午睡
- 厨房准备饮料
- 阳台休息

## 7. 可复用提示词块
```text
DeepSeek 鲸鱼娘穿宽松白色纯棉短袖 T 恤，领口和袖口有浅蓝滚边，胸前只有小型蓝色鲸鱼标志；下身穿深海蓝宽松居家短裤，松紧腰头和抽绳。简洁、自然、凉爽。
```

## 8. 禁止偏差
1. 不出现女仆元素、蕾丝、胸衣、吊袜带。
2. 不把 T 恤画成贴身内衣或透明上衣。
3. 不堆叠装饰带和无功能绑带。
4. 尾根开口必须符合骶尾部正中位置。
