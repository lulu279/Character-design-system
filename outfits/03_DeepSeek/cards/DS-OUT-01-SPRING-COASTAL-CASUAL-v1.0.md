# DS-OUT-01｜春季海岸轻行装

**角色：** DeepSeek 鲸鱼娘  
**季节：** 春季  
**版本：** v1.0  
**状态：** `design_defined_pending_validation`  
**定位：** 春季海岸漫步、雨后旅行和轻度户外活动。核心是轻量防风、防泼水、可快速穿脱；与夏季运动装相比应更有层次，并优先体现春季防雨功能。

## 1. 设计概念
春季海岸漫步、雨后旅行和轻度户外活动。核心是轻量防风、防泼水、可快速穿脱；与夏季运动装相比应更有层次，并优先体现春季防雨功能。。本卡用于固定衣装结构；具体动作、机位、表情和环境仍由单张 SHOT 指定。

## 2. 服装层级与部件
### 外层：浅蓝白轻量防风外套
短款或髋上长度，轻量防风尼龙；可拆卸或可收纳帽兜；前襟防水拉链；袖口弹性收束；下摆抽绳；肩部和腋下可使用透气网布。建议以浅蓝主片、冷白拼片区分前后结构。

### 内层：白色速干上衣
采用白色速干短袖或轻薄长袖版本。春季版建议长袖作为与夏装的差异化选项；胸前只保留小型鲸鱼标志和蓝色窄滚边。

### 下装：蓝白功能短裤
中等长度，覆盖大腿上段至中段；弹性腰头和抽绳；两侧插袋；裤腿宽松，允许蹲坐和跨步。

### 鞋袜与携行
轻量防水运动鞋或涉水鞋，白灰与浅蓝配色；透气短袜；小型防水斜挎包；折叠雨具可作为场景道具。

## 3. 配色与材料
| 部件 | 色彩 | 材料 / 表面 |
|---|---|---|
| 外套 | 浅蓝 / 冷白 | 防风尼龙、透气网布 |
| 内搭 | 白 / 浅蓝 | 速干针织 |
| 短裤 | 蓝白拼色 | 弹性运动布 |
| 鞋履 | 灰白 / 浅蓝 | 防水合成材料 |
| 配件 | 深海蓝 | 防水织物 |

## 4. 尾根与结构适配
裤装和外套后腰均需为虎鲸尾预留骶尾部正中开口；外套下摆可采用中央分割或短后摆，避免压住尾根。开口边缘柔软包边，不得从髋侧出尾。

## 5. 动作与穿着适配
适合快走、跨越浅水、蹲下拍摄、弯腰整理背包。帽兜、下摆和长发受同一海风方向影响；鞋底应与湿地面有可靠接触。

## 6. 推荐场景
- 樱花海岸步道
- 雨后码头
- 春季潮池观察
- 海滨公园摄影

## 8. 禁止偏差
1. 不要与夏季服装完全相同；春季需要外套层次和防雨属性。
2. 不要加入蕾丝、吊袜带或女仆装元素。
3. 不要使用厚重冬季填充层。
4. 尾巴不得从髋侧或完整布料表面穿出。

## 9. 备注与待验证项
现有春季设计板与夏季板的廓形较接近。建议下一版通过长袖内搭、可收纳雨帽和防水闭合鞋强化春季差异；这是待审阅的改进建议，不视为已确认修改。
