# DS-IN-03｜秋季深海针织

**角色：** DeepSeek 鲸鱼娘  
**季节：** 秋季室内  
**版本：** v1.0  
**状态：** `design_defined_pending_validation`  
**定位：** 以中厚针织为主的慵懒秋季居家服，与春季薄开衫形成明显区别。

## 1. 设计概念
以中厚针织为主的慵懒秋季居家服，与春季薄开衫形成明显区别。。本卡用于固定衣装结构；具体动作、机位、表情和环境仍由单张 SHOT 指定。

## 2. 服装层级与部件
### 内搭
奶白色棉质长袖打底衫；圆领；合体但不紧绷；下摆略长于外层毛衣。

### 外层毛衣
雾蓝色宽松针织毛衣；落肩；圆领或小半高领；宽松长袖；袖口和下摆罗纹；衣长覆盖腰部至髋部上方；中等粗细平针，局部可有少量麻花组织。

### 下装
灰蓝色直筒居家长裤；中高腰弹性腰头与抽绳；宽松裤腿；膝部有活动余量；裤脚柔软罗纹或自然垂落。

### 袜鞋配件
白色或灰蓝中筒针织袜；深蓝毛绒拖鞋；可选简洁发夹。

## 3. 配色与材料
| 部件 | 色彩 | 材料 / 表面 |
|---|---|---|
| 内搭 | 奶白 | 棉质针织 |
| 毛衣 | 雾蓝 | 中厚针织 |
| 长裤 | 灰蓝 | 棉质卫衣布 / 针织 |
| 袜子 | 白 / 灰蓝 | 针织棉 |
| 拖鞋 | 深蓝 | 毛绒织物 |

## 4. 尾根与结构适配
毛衣后腰采用柔软中央分割；长裤后腰设置尾根开口，使用弹性针织包边，避免厚布挤压尾根。

## 5. 动作与穿着适配
适合盘腿阅读、沙发休息、喝咖啡和制作热饮。毛衣袖口可自然堆叠，但不能遮挡手部操作。

## 6. 推荐场景
- 秋日雨天阅读
- 沙发休息
- 窗边喝咖啡
- 厨房制作热饮
- 书房整理资料

## 7. 可复用提示词块
```text
DeepSeek 鲸鱼娘穿雾蓝色宽松落肩针织毛衣，内搭奶白棉质打底衫，下身穿灰蓝直筒居家长裤，搭配中筒针织袜和柔软拖鞋。针织纹理清晰，氛围安静温暖。
```

## 8. 禁止偏差
1. 不要与春季薄开衫混为同一廓形。
2. 不使用硬质户外机能面料。
3. 不添加女仆围裙或蕾丝。
4. 尾根周围不能堆积厚布。
