# DS-SPECIAL-LACE-INDOOR｜蓝白蕾丝室内套装

**角色：** DeepSeek 鲸鱼娘  
**版本：** v1.1  
**状态：** `design_constraints_locked_pending_clean_turnaround_validation`  
**参考：** 用户提供的蓝白蕾丝室内套装图；本包 `references/user-supplied/DeepSeek_IndoorLace_UserReference.png`

## 1. 设计定位

蓝白色、轻盈、优雅的室内特别套装。它是独立特别服装资产，不替代四季普通家居服。场景可包括阅读、梳妆、卧室休息、茶点和夜间室内活动。

## 2. 上身结构

- 象牙白 / 冷白贴身胸衣，心形领口，白色蕾丝窄包边。
- 胸前中央设置深蓝色蝴蝶结；胸衣下缘有独立蕾丝装饰。
- 肩部为独立露肩蓬松袖套，白色主体与深蓝内层 / 下缘呼应；袖口柔软蕾丝。
- 颈部使用蓝白贴颈饰和鲸鱼主题扣件。
- 不自动增加与参考图无关的基础内衣层。

## 3. 腹部与腰侧缎带

- 胸衣下缘至短裙腰线之间保留完整中央镂空。
- 左右侧腰各有一组深海蓝窄幅缎带，采用连续 X 形交叉排列。
- 每组缎带上端固定在胸衣侧缝的加固袢环 / 金属孔眼，下端固定在短裙腰侧的加固袢环 / 金属孔眼。
- 两端必须真实连接并承受合理张力；禁止无固定点的悬空交叉带。
- 缎带只连接服装上下两部分，不横跨腹部中央，不额外垂挂多余长带。

## 4. 短裙

- 低腰结构，腰线低于尾根。
- 比最初版本适当加长，不能呈现内裤式短度；裙摆覆盖大腿上段。
- 两至三层蓝白交替裙片，褶皱适量，蕾丝只在必要的裙边使用。
- 后腰为尾根留出中央开口，尾巴从骶尾部正中、裙腰上方自然伸出。

## 5. 吊袜带与长袜

吊袜带与侧腰缎带是两套完全独立的系统。

- 左右大腿各一条深蓝色窄幅吊袜带。
- **按最新参考图：** 吊袜带上端固定在短裙内侧下缘的加固袢环；下端使用小型银色调节扣 / 夹具连接白色长袜顶部的蕾丝袜口。
- 不连接胸衣，不与侧腰 X 形缎带混合，也不使用连续环绕腰部的吊袜腰带。
- 白色长袜采用宽幅蕾丝袜口，保持柔软贴合。

## 6. 材质与配色

| 部位 | 色彩 | 材质 |
|---|---|---|
| 胸衣 | 象牙白 | 弹性缎面、窄蕾丝 |
| 裙片 | 深海蓝 / 冷白 | 轻质缎面、薄纱 |
| 袖套 | 白 / 深蓝 | 柔软薄纱与缎面 |
| 腰侧缎带 | 群青蓝 | 窄幅缎带 |
| 吊袜带 | 深海蓝 | 弹性缎带、银色夹具 |
| 长袜 | 白色 | 弹性针织、蕾丝袜口 |

## 7. 尾根与解剖适配

虎鲸尾从骶尾部正中自然延伸，尾根有体积并与躯干连续。短裙后腰降低到尾根下方，并设置专门的中央开口；尾巴从裙腰上方露出，不穿透完整裙片，也不从髋侧或腰侧出现。


## 9. 失败判据

1. 腹部中央被布料填满。
2. 侧腰 X 形缎带没有真实连接点。
3. 吊袜带连接到胸衣或与腰侧缎带混成一体。
4. 短裙过短，呈现内裤式轮廓。
5. 尾巴从髋侧伸出，或穿透完整裙片。
6. 袖套与胸衣被错误画成一件连体袖装。
