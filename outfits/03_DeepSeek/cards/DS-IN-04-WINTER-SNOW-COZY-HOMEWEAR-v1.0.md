# DS-IN-04｜冬季暖雪居家服

**角色：** DeepSeek 鲸鱼娘  
**季节：** 冬季室内  
**版本：** v1.0  
**状态：** `design_defined_pending_validation`  
**定位：** 冬季室内保暖服装，以奶白抓绒连帽衫、浅冰蓝保暖内搭和深海蓝抓绒长裤构成。

## 1. 设计概念
冬季室内保暖服装，以奶白抓绒连帽衫、浅冰蓝保暖内搭和深海蓝抓绒长裤构成。。本卡用于固定衣装结构；具体动作、机位、表情和环境仍由单张 SHOT 指定。

## 2. 服装层级与部件
### 内搭
浅冰蓝保暖长袖上衣；圆领或小半高领；合体但不紧绷；柔软保暖针织。

### 外层连帽衫
奶白色宽松抓绒连帽衫；落肩；套头或短半拉链；宽松长袖；袖口弹性罗纹；帽内浅蓝短绒；胸前小型鲸鱼标志；柔软短绒而非户外羽绒面料。

### 下装
深海蓝抓绒居家长裤；中高腰松紧与抽绳；直筒或略宽松；裤脚柔软罗纹；内侧细腻保暖绒层。

### 袜鞋配件
厚款白色或浅蓝保暖袜；奶白或浅蓝毛绒室内拖鞋；可选柔软围脖。

## 3. 配色与材料
| 部件 | 色彩 | 材料 / 表面 |
|---|---|---|
| 内搭 | 浅冰蓝 | 保暖针织 |
| 连帽衫 | 奶白 | 短绒抓绒 |
| 帽内衬 | 浅蓝 | 短绒 |
| 长裤 | 深海蓝 | 加绒卫衣布 |
| 袜鞋 | 白 / 浅蓝 | 保暖针织、毛绒织物 |

## 4. 尾根与结构适配
连帽衫后腰与长裤后腰都需设置柔软尾根开口；尾根周围避免厚绒堆积和硬质拉链头。

## 5. 动作与穿着适配
适合端热饮、阅读、看电影、烘焙和壁炉旁休息。袖口不应妨碍拿杯子或操作厨具。

## 6. 推荐场景
- 冬夜卧室
- 雪天窗边
- 壁炉旁阅读
- 沙发看电影
- 冬日烘焙

## 7. 可复用提示词块
```text
DeepSeek 鲸鱼娘穿奶白色宽松抓绒连帽衫，内搭浅冰蓝保暖上衣，下身为深海蓝加绒居家长裤，搭配厚白袜和毛绒拖鞋。柔软蓬松、温暖、普通日常家居氛围。
```

## 8. 禁止偏差
1. 不要使用户外远征羽绒服廓形。
2. 不添加女仆装、蕾丝或吊袜带。
3. 不要让厚绒压住尾根。
4. 不要用夸张的室内装饰填满背景。
