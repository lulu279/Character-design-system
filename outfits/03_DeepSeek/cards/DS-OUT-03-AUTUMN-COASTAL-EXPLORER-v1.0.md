# DS-OUT-03｜秋季海岸徒步装

**角色：** DeepSeek 鲸鱼娘  
**季节：** 秋季  
**版本：** v1.0  
**状态：** `design_defined_pending_validation`  
**定位：** 面向秋季山地、海岸森林和礁石地形的中短途徒步。较夏装更厚实，强调耐磨、分层和携行能力。

## 1. 设计概念
面向秋季山地、海岸森林和礁石地形的中短途徒步。较夏装更厚实，强调耐磨、分层和携行能力。。本卡用于固定衣装结构；具体动作、机位、表情和环境仍由单张 SHOT 指定。

## 2. 服装层级与部件
### 外套：深海蓝软壳夹克
中短款立领；防风软壳面料；防水拉链；肩部、肘部耐磨补强；两侧拉链口袋；腋下透气结构；袖口魔术贴；下摆调节绳。

### 内搭：灰蓝长袖速干衣
合体但不紧绷；圆领或半高领；长袖；吸湿排汗弹性面料。

### 下装：灰蓝工装短裤
中高腰，长度覆盖大腿中段；立体多口袋；织带腰带与金属扣；宽松裤腿；后腰尾根专用裁片。

### 防护与鞋履
可拆卸软质护膝或护腿套；中帮防滑徒步鞋、加固鞋头、防水鞋面；透气徒步袜。

### 携行装备
轻量登山包、胸带、水壶、指南针、运动腕表；可选登山杖。

## 3. 配色与材料
| 部件 | 色彩 | 材料 / 表面 |
|---|---|---|
| 软壳外套 | 深海蓝 | 软壳防风面料 |
| 内搭 | 雾灰蓝 | 弹性速干布 |
| 工装短裤 | 灰蓝 | 耐磨弹性织物 |
| 护膝 | 深灰蓝 | 耐磨复合材料 |
| 鞋履 | 灰蓝 / 深蓝 | 防水合成材料 |
| 背包 | 深海蓝 | 防撕裂尼龙 |

## 4. 尾根与结构适配
短裤后腰中央设置尾根开口；外套后下摆采用中央分割，避免压住尾根。背包腰带与胸带不得压迫尾根或限制尾巴摆动。

## 5. 动作与穿着适配
支持上坡、跨步、蹲下整理装备和坐在岩石上休息。登山杖与承重手、支撑脚必须形成合理受力关系；背包重量通过双肩和腰带分担。

## 6. 推荐场景
- 秋季海岸森林徒步
- 落叶覆盖的礁石坡
- 海岸观景平台
- 林间露营
- 溪边取水

## 7. 可复用提示词块


## 8. 禁止偏差
1. 不要沿用夏季短外套与凉鞋。
2. 不要堆叠无功能挂带。
3. 护膝不能遮挡正常膝关节活动。
4. 尾根不能被背包腰带或衣物挤压。

## 9. 备注与待验证项
现有秋季设计板可作为形象参考；完整动作和尾根结构仍需在侧后攀登姿势中验证。
