# YY-IN-HOME-LOUNGE｜棉白 T 居家服

**角色：** Yaoyao（摇摇）  
**版本：** v1.0  
**状态：** `user_direction_confirmed_design_defined_pending_scene_validation`  
**定位：** 普通日常家居服、休息、阅读、居家活动

## 1. 设计定位

这是 Yaoyao 的私人居家休息服，不是工作制服。用户明确选择室内使用普通白色棉 T；低腰家居短裤可接受。室内休憩不出现女仆元素。

## 2. 服装结构

### 上装：白色棉质 T 恤
- 宽松自然廓形，圆领、短袖、轻微落肩。
- 衣长覆盖腰部，可略过髋部上方。
- 面料为中等厚度棉质针织，避免透明、过薄或紧身内衣效果。
- 胸前仅保留小型 Z 标或极简 GLM 标识；不添加大面积科技印花。

### 下装：柔软居家短裤
- 深灰、炭黑或深蓝灰色柔软短裤。
- 允许自然低腰；腰头为松紧或抽绳结构。
- 裤腿适度宽松，保留机械髋部与大腿活动空间。
- 不添加吊袜带、腿环、胸衣式带条或多余机能挂载。

### 可选配件
- 白色短袜或简洁室内拖鞋。
- 简单 Z 字发夹可以保留为角色识别锚点。
- 不需要女仆头饰、围裙或工作用装饰。

## 3. 机械结构适配

- 机械膝关节、踝关节和髋部接口必须可见或有合理活动余量。
- T 恤和短裤不得遮盖所有机械结构，除非单图任务明确要求。
- 数字尾巴是投影 / UI 型非实体结构，不得画成实体生物尾巴或布料尾饰。

## 4. 配色与材质

| 部位 | 颜色 | 材质 |
|---|---|---|
| T 恤 | 暖白 / 纯白 | 棉质针织 |
| 短裤 | 炭黑 / 深灰蓝 | 柔软棉混纺 |
| 标识 | GLM 蓝 | 小面积印花 / 刺绣 |
| 袜鞋 | 白 / 浅灰 | 棉纱、软底织物 |

## 5. 场景

卧室休息、阅读、桌边工作间歇、空调房、普通客厅。做巧克力或维护等工作活动时，可按工作任务选择工作制服；不能把工作制服反向当成居家休息服。

## 6. 稳定提示词

```text
Yaoyao 穿普通宽松白色棉质短袖 T 恤和深色柔软居家短裤，低腰短裤可接受。服装简洁、日常、舒适；不出现女仆头饰、围裙、蕾丝、荷叶边、胸衣式内搭或吊袜带。保留银灰短发、蓝紫发梢、琥珀眼、Z 发夹、机械关节和非实体数字投影尾巴。
```

## 7. 禁止偏差

1. 把室内服装画成内衣 / 胸衣套装。
2. 添加女仆头饰、围裙、蝴蝶结、荷叶边或工作制服元素。
3. 把投影尾巴画成实体尾巴。
4. 遮住机械关节或改变关节结构。
5. 过度装饰普通卧室背景。

## 8. 历史版本说明

此前半透明罩衫、黑色胸衣式内搭和过多带条的室内方案已被用户明确放弃。对应图片仅放在 `references/review-only/superseded/`，不得作为当前卡片的服装依据。
