# YY-OUT-URBAN-EXPLORER｜城市机能探索装

**角色：** Yaoyao（摇摇）  
**版本：** v1.0  
**状态：** `direction_confirmed_details_pending_validation`  
**定位：** 城市通勤、户外运动、轻量探索、短途出行

## 1. 设计定位

与室内棉白 T 完全分开的城市机能服装。采用短款技术夹克、运动内搭、功能短裤 / 短裙裤和模块化挂载，突出运动性与机械结构适配。不是女仆服，也不是室内家居服。

## 2. 服装层级

### 外层：短款机能夹克
- 珍珠白 / 银灰主色，GLM 蓝和蓝紫作为识别点。
- 短款轻量防风廓形，可拆卸袖片或局部透气网布作为可选模块。
- 立领或短帽体；前襟拉链；肩部与背部有明确分割线。
- 小型 Z 标识和少量功能口袋。
- 夹克后背避开脊柱散热通道与尾椎接口。

### 内层：高领运动内搭
- 石墨黑或深灰蓝高领运动上衣。
- 吸汗、弹性、贴合但不压迫机械接口。
- 胸前小型 Z 标识。

### 下装：不对称功能短裤 / 短裙裤
- 深灰 / 炭黑为主，局部银灰和 GLM 蓝拼接。
- 一侧可有短裙片式外层，但主体仍是功能短裤。
- 侧袋、拉链袋和模块接口必须有实际固定点。
- 腰部采用功能腰带与可调节扣具。

### 模块挂载
- 小型工具包、通讯模块或身份卡。
- 腿部固定带仅在确有模块固定需求时使用，不应成为纯装饰束带。
- 鞋履采用轻量运动鞋或短靴，兼容机械踝关节。

## 3. 机械结构适配

- 肩、肘、髋、膝、踝关节保留完整活动范围。
- 裁片边缘不得跨越关节转轴或检修盖板。
- 后背结构避开散热通道与尾椎投影接口。
- 数字尾巴是非实体投影 / UI 元素，可在动作中改变弯曲与光标方向，但不产生实体重量或遮挡衣物。

## 4. 配色与材质

| 部位 | 颜色 | 材料 |
|---|---|---|
| 夹克 | 白 / 银灰 | 轻量机能防风布 |
| 内搭 | 石墨黑 | 高弹吸汗运动布 |
| 短裤 | 炭黑 / 深灰 | 耐磨弹性织物 |
| 功能件 | GLM 蓝 / 蓝紫 | 织带、硬质轻量扣具 |
| 鞋履 | 白 / 深灰 / 蓝 | 运动合成材料 |

## 5. 适用场景

城市通勤、街区行走、公园慢跑、楼顶休息、短途户外、设备检查。动作应体现服装的实际用途，不必每张都看向镜头。

- 腰带、腿部固定带是否有真实承力和固定点。
- 后背散热通道和尾椎投影接口是否在正、侧、背视图中连续。
