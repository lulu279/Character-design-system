# 历史服装资产恢复与审计报告 v2.1

本轮只恢复已知历史服装主题、用户明确修改、历史生成图示及可追踪的构造，没新增无来源的服装系列。Markdown 卡片不改变 `角色卡`；场景、光影、歌词动作仅作为服装使用场景示例。

**核心限制：** 项目库中 `二创角色设计_六角色详细服装提示词_MD_CSV源文件_v2.0.zip`、`03_DeepSeek_...v2.0.zip`、`06_Yaoyao_...v2.0.zip`、`07_UNASSIGNED_...v2.0.zip` 已定位，但请求原始字节时返回 `This Project file does not have an authorized raw-byte materialization path.`。因此本次不能读取 ZIP 内旧卡 ID、完整旧提示词或校验其修改历史，不进行覆盖/自动合并。本包只作为 v2.1 增量恢复包。

## 已有强证据的部分

- DeepSeek：历史蓝月五服系列图、多个歌词故事板、两张黑白服装原始截图、泳装/日常/家居用户历史约束。D-01/D-02 在历史会话检索中有部分结构文本，D-03 仅名称和主题可确认。
- Yaoyao：经典女仆三视图、GLM 仿生机械结构、七阶段分层图和接口说明；模块化连身衣用户确认内网纱外乳胶，并要求削减网纱覆盖；经典女仆装明确要求三视图。
- 不属于 Yaoyao：此前误生粉发角色被明确指出不是摇摇，同时用户表示形象本身不错，希望保留。

## 需要保留的历史修改差异

1. Yaoyao 模块化连身衣：先设计可拆的两个层次；确定**内层细网纱、外层乳胶**；随后用户明确要求**大幅减少内层网纱覆盖，使其与最终外观相一致**。早期“外层哑光技术织物”不能自动视为最终版本。网纱覆盖整躯干或像一件透明连体紧身衣都是被否定的错误。
2. Yaoyao 机械接口：上肢与下肢均为机械结构；肩、肘、髋、膝、足部保留活动范围；背部脊柱散热通道和骶尾数字尾巴投影接口必须可解释。历史工程图仅视觉参考，不宣称完成机械设计验证。
3. DeepSeek 虎鲸尾：由骶尾中线自然延伸、基部足够粗、收束至水平双叶尾鳍；服装必须有对应后腰开口，不能从侧腰和裙面生长。
4. 原图的黑白哥特镂空衣和荷叶边泳装是两个不同原型。涉水仅是其中一轮图像场景，不能把水滴算作服装固有材料。
5. Claude 伪装衣必须与旧参考素材保持相同的可辨识元素。本次未恢复完整服装原图，故本卡只记录归属和硬约束，不虚构完整同款。
