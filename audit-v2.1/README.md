# 二创角色设计系统｜历史服装资产恢复与审计包 v2.1

这是在现有 v2.0 资产库之外的**增量恢复包**，不是自动覆盖补丁。包含 DeepSeek、Yaoyao 与未归属服装单卡、索引、原图小样证据及详细审计结论。

## 目录

- `DeepSeek/` — 鲸鱼娘服装卡，每套单独 Markdown；
- `Yaoyao/` — 摇摇服装卡，每套单独 Markdown；
- `UNASSIGNED/` — 未定归属、错误角色候选等暂存服装卡；
- `REFERENCES/` — 已可读取的历史图片原始文件，没有重新生图；
- `00_统一服装索引.md`、`INDEX.csv` — 跨角色索引；
- `AUDIT/01_审计结论.md` — E1-E4 和未完事项；
- `AUDIT/EVIDENCE_IMAGES.csv` — 图像 ID、原始文件 ID、包内文件映射。

## 如何使用

优先从索引找到服装。每卡第 2～11 节记录历史结构，第 12 节保留“原始完整提示词”的核验槽，第 13 节是**新写的可生图提示词**。第 13 节即使完整也不能自动变成第 12 节；标明历史原图缺失的 Claude 伪装和罗密欧占位卡不宣称已实现忠实复刻。

**特别说明**：严格遵守用户提出的“服装卡≠角色卡”，禁止把歌词角色扮演、粉发角色的错误生成图或胶片/湿润风格当作角色永久身份。
